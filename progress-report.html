Tech Stack Overview
End-to-end summary of frontend, backend, and infra
Frontend
React 18 + Vite · Tailwind CSS · Framer Motion (scroll-driven animations) · Lucide React icons · React Router v6 · Capacitor (iOS/Android shell)
Authentication
Firebase Auth (email/password + email verification gate) · Custom AuthContext with plan field hydration from Firestore · RequireAuth / RequireGuest route guards · Email verification enforced before workspace access
State & Data
Firestore (cloud) · localStorage (Starter sandbox fallback) · React useState / useEffect · No global state manager (intentional for simplicity)
Backend (Firebase Functions)
Node.js Cloud Functions (asia-southeast1) · createCheckoutSession — PayMongo checkout URL generator · PayMongo webhook handler for subscription events · Firestore security rules scoped per-user UID
Payments
PayMongo (PH) for GCash, Maya, cards, bank transfer · Checkout session created server-side (no keys in browser) · Webhook updates users/{uid}.plan on payment confirmation
Deployment
Firebase Hosting (SPA rewrite rules) · Firebase Functions (asia-southeast1) · Capacitor build for iOS/Android · Vite production build with manual chunk splitting

Why ₱599 Family is fair
₱599/mo is ~2 cups of Starbucks. For a family dealing with multi-creditor debt, tuition tracking, and savings goals, replacing missed payment penalties (₱500–₱2,000 per late bill) in the first month more than pays for the subscription. Comparable: Canva Pro ₱549, Netflix Standard ₱459. Family is priced in that window.
Why ₱1,499 Pro is defensible
BIR-ready tax export alone saves families 4–8 hours per filing season. AI insights + custom categories turn Famly into a proper CFO tool. At ₱1,499 that's ₱50/day — less than a single Grab ride. Targeting households managing ₱100k+ in annual obligations.
